# 当前运行状态与验收边界

更新于 2026-10-09。本文区分正在生产运行的功能、隔离回归证据与尚未完成的验收；其余架构文档中的“当前未上线”等段落是各阶段的历史记录，不能作为今天的部署指令。

## 仓库和运行边界

通用 Rust 服务、身份、学习解释器、Web 页面、后台、生成契约、配音和运维工具属于 Chef。Brioche/Hargow 只保存产品配置、品牌素材、构建装配和固定框架引用；作者课程分别属于 brioche-courses/hargow-courses。两产品使用独立 HTTPS 入口，共用 PostgreSQL 和账号身份，成员权限、会话、课程、学习设置、进度、收藏、复习及后台数据按可信服务器产品配置隔离。

生产已经使用独立 identity/learning/Web/内部 Traefik，共八个产品服务。身份 schema 为 `chef_identity`，学习/内容 schema 为 `public`，迁移边界为 32，分离布局为 24 步。运行连接采用专用非所有者权限；维护命令和凭据不进入 Web。旧 combined 服务与品牌准备页均停用，不能用旧 Compose 覆盖新的生产布局。HTTPS 由外部网关处理，不恢复宿主 HTTP 30075 映射。

真实部署和备份证据见 [Hargow 生产记录](https://github.com/Ronbb/hargow/blob/main/docs/production-20261008.md)。本机私有配置、数据库快照、媒体、供应商密钥及账号令牌不提交公开仓库。

## 所有者明确延期的验收

2026-10-09，所有者明确将以下两项搁置，暂不作为当前开发或交付的阻塞项：

- 真实 iPhone Safari 的阅读/词音/长按/倍速/暂停续播及实机辅助访问验收。保留已有 Chromium 和 Windows WebKit 自动化证据，实机验收状态为延期。
- 异盘或 NAS 加密备份的实际存放，以及基于该副本的灾难恢复验收。已有本机备份、密文校验和隔离恢复证据继续有效，异盘验收状态为延期。

延期不表示这些验收已经通过。重新开展时再收集设备结果和备份目标路径；当前无需为这两项反复请求信息或等待。
