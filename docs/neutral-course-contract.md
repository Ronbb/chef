# 课程 2.0 公开契约

`neutral::NeutralLesson` 是 Chef 的完整语言中立公开课程模型，schemaVersion 为 2.0，明确记录 targetLanguage 与 explanationLanguage。目标语言支持 fr-FR/yue-Hant-HK，解释语言支持 zh-CN/zh-Hant-HK；等级和单元 ID 沿用通用作者编号规则，不自动赋予粤语 CEFR 等级。

标题使用 target/zh；对话和短文的段落使用 NeutralSegment.reading，词汇 lemma 和语法例句 target 也使用 ReadingText。原句、作者词段与注音保持独立。填空模板使用 templateTarget。十类教学块、三种练习、角色快照、素材、音频、步骤、完成策略和回顾引用全部保留，未知字段在各层拒绝。公共模型不接纳 serverOnly 或 editorial；私有判分与离线作者校验已在服务器作者层实现；共享导入已接通版本分派；发布与学习服务仍须后续装配。

## 共用验证

结构校验复用原有课程内核：ID/版本、角色和锚点、说明目标、步骤可达性、练习归属、完成引用、知识点和媒体描述均保持原规则。一个私有的临时结构视图只映射字段位置，不返回、不保存、不将粤语称为法语课程。目标语言以真实 locale 传入角色校验；旧 1.0 入口始终固定法语策略，外部调用不能用该内部入口绕过旧契约。

媒体校验复用同一音频内核，仍校验真实描述、哈希和 URL、时长、整句/语段父区间、引用和时间顺序。旧 1.0 保留原词界规则；2.0 对全部正文先校验作者词段，再要求每条词音 cue 精确对应该词段，允许相邻汉字与作者定义的语块，不按空格推断粤语词界。没有推造或平均分配时间轴。

Rust 生成 NeutralLesson/NeutralBlock/NeutralExercise 及其嵌套类型的 TS 和 neutral-lesson.schema.json；导出名独立，不覆盖现有 PublicLesson/Block/Exercise 文件。产品库不增加模型或解释器副本。Schema 只表达结构约束，引用、语言一致性、词段和音频语义必须执行 Rust validate。

## 离线作者校验与判分

`chef-server check` 按 schemaVersion 精确分派：1.0 使用原法语模型，2.0 使用 NeutralLesson；缺失、类型错误和未知版本拒绝。`check-release` 可以校验引用混合版本的本地课源，仍检查课 ID、版本、等级、单元和唯一课源。通过只证明本地结构与规则一致，不代表产品课程可以导入或发布。

公开投影只移除四个已知作者字段 serverOnly/editorial/assetRefs/audioRefs，其他未知字段仍由严格模型拒绝。2.0 作者 Schema 仅保留在服务端，不向 Web 导出答案。媒体引用预检查允许在注册描述装配之前校验教学内容；完整检查仍要求有效的公开描述。错误保留原课源文件、行列和 JSON Pointer，运行时判分只返回不含答案的 InvalidContent。

三种题型通过借用公共选项/词块视图复用同一个私有规则解析与判分内核，不把粤语课程序列化成法语模型。保留未知选项拒绝、文本长度上限、大小写策略、Unicode 归一化和重复显示词块规则；繁简转换不自动执行。判分已可直接接收 NeutralLesson，但版本化学习会话已接入，概览/首页/复习/收藏已提供 v2 只读显示与共享事务。

## 版本化导入与媒体装配

上传预检查、作者 import 预检查和共享导入事务执行同一个精确版本分派。注册图片与录音按可信产品解析固定版本，之后执行完整模型与私有规则校验；保存的 public_document 保持源版本，2.0 不写入法语字段或私有答案。server_document 保留私有规则和装配后的注册描述，重复导入比较同一不可变内容，不额外写审计。导入不激活目录或直接授权课程。

CheckedLesson 仅是服务器内部的版本容器。图片、角色、录音登记与真实对象验证借用两种模型共有的描述字段，复用同一实现；场景插图引用保留各自块索引。课程检查仍校验真实目标语言、角色、作者词段与音频引用。角色注册接受契约定义的 fr-FR/yue-Hant-HK，拒绝别名；1.0 法语课程依旧拒绝粤语角色。管理角色创建、声音计划和学习界面还需接通目标语言。

registered check 为只读操作，同时核对注册快照、头像版本、描述、真实文件哈希、录音解码时长/采样率/声道和来源。即使直接嵌入描述并省略引用字段，导入仍检查本产品的图片、角色与录音归属。错误定位映射回原作者引用，不回显答案。

隔离 PostgreSQL 合成用例覆盖完整布局与独立 H 状态初始化、粤语角色登记、真实 SVG/MP3 装配、2.0/粤拼保存、外产品引用及嵌入描述拒绝、检查零写入、不可变重试、文件损坏，以及最终审计失败全部回滚。合成录音和时序只验证协议，不代表正式粤语或对齐质量。H CLI 写入/serve 门槛和生产部署尚未开放。 Rust 工作区测试及新增 PostgreSQL 用例通过；现有 admin、author_runtime、author_scopes、learning、recording 共十项 PostgreSQL 回归通过。

## 旧版本只读适配与详情接口

`NeutralLesson::try_from(&PublicLesson)` 先执行原 1.0 法语契约检查，再转换公开显示模型：title.target、ReadingText、语法 target 和 templateTarget。课编号/版本、锚点、题目选项/词块编号、完成策略、角色、素材描述、知识点录音及所有录音 cue 保持。转换只借用源，不修改原课程、数据库、课源哈希、学习进度或录音时间。

旧法语文本的默认词段只用于这个明确的兼容入口，保留 Unicode scalar 坐标、撇号、复合词和组合音标字符，不归一化原文。已有词音 cue 的范围优先且原样保留；未覆盖文字才补法语显示词段。不能无损表示的重叠旧 cue 明确拒绝并报告定义位置，不合并、不重算时序、不丢词。原生 2.0 粤语继续使用作者显式词段，不经过此词段推导，也不凭空补粤拼。

`neutral::decode_public` 精确接纳公开 1.0（只读适配）或 2.0（原样验证）；未知版本、私有字段和错误形状拒绝。新增 GET `/api/v2/lessons/{id}`（可选 revision）复用旧详情的可信产品与可用性查询。旧 `/api/lessons/{id}` 保留原响应格式。两个版本共用当前目录、已发布状态与硬撤回判断，产品不能由 query/header 选择；Hargow 不使用法语开发夹具作回退。

契约回归覆盖原字段往返等价、源不变、实测 cue/知识点录音保留、Unicode 词段、不可表示旧 cue 及严格公开版本分派。现有 48 课回归同时以原判分和适配后判分验证正确/错误答案。另从实际生产只读导出 public_document 到忽略目录，用 `cargo run -p brioche-course-contract --example check_legacy_adapter --locked -- <public-snapshot.json>` 校验 48 课、517 音频描述、6882 条 cue；没有导出身份或私有判分，没有持久化或发布。

实际 Router 测试验证旧响应原样、新法语响应、版本参数/外产品字段拒绝与 H 开发夹具无回退。隔离 PostgreSQL 的原生粤语课程验证当前/指定版本读取、粤拼和词段保持、私有字段不返回、跨产品/未发布拒绝，以及撤回后当前404/指定版本410。真实 H serve、学习写入、前端和粤语配音仍待贯通，生产与产品 pin 保持。

## 版本化目录与搜索

GET `/api/v2/catalog` 返回语言中立的等级、单元和课程摘要（title.target、targetLanguage、explanationLanguage）。1.0 只转换摘要字段；原生 2.0 保留真实语言。Rust DTO 和生成 TS 位于 Chef，产品仓库不复制模型或搜索实现。

两个目录版本共用一次 SQL 快照查询当前发布指针、固定 manifest、已发布状态、产品归属和硬撤回记录；只取公开摘要，搜索时额外取词汇文字及注音，不返回完整正文、知识点或私有判分。保留 manifest 的课程顺序和空分组清理。`q` 延续 120 字符上限、控制字符拒绝、Unicode 兼容分解/大小写/法语重音检索与全部词匹配；粤语搜索包含作者原文、中文释义和粤拼，不自动推导或转换注音。产品仍由可信装配选定，query/header 不能切换，Hargow 开发入口不回退法语 fixture。
