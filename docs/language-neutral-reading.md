# 语言中立正文与注音契约

Chef 的 `ReadingText` 是下一版课程解释器的共用正文原语：原句 `text`、作者标注的 `words` Unicode 范围、独立 `pronunciations`。它不使用 `fr` 字段，不把粤拼塞进原句，也不依赖空格猜测粤语词界。Rust 是真源，TypeScript 与 JSON Schema 由同一 exporter 生成，产品仓库不维护副本。

目标语言当前明确支持 `fr-FR` 与 `yue-Hant-HK`，不接受别名。角色语言核对用目标语言的精确 locale，不能把普通话角色配置当粤语。语言标签不是提供方音色能力证明，正式粤语配音还须核对实际模型/音色、试听与来源。

词或语块范围采用半开区间 `[start,end)`，索引单位是原句的 Unicode scalar，不是 UTF-8 字节或 JavaScript UTF-16。范围须有序、非空、互不重叠并覆盖原句全部字母和数字，不能越界或只有标点/边界空白；标点可以处于词段之间。正文按原样保留，验证不会进行 NFC、简繁转换或重写，因此音频与显示能够引用相同字符序列。

注音只能附着于一个精确作者词段；同一系统在同一词段至多一条。支持 IPA 与粤拼，粤拼只用于粤语，须为小写字母音节加 1–6 声调数字，音节之间单个空格。此项是格式验证，不证明音节与汉字的语言学对应准确。正文最多 32768 UTF-8 字节、1024 个词段；注音最多 256 字节并拒绝控制字符。各对象严格拒绝未知字段。

词语录音的字符范围必须对应作者词段。该检查没有生成或估算时间轴：音频开始/结束毫秒仍须来自真实测量和既有音频验证。扩展汉字和组合字符测试验证的是索引协议，合成测试不作为粤语发音质量证据。
